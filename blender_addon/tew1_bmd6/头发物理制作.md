# TEW1 Blender 头发物理（TEW Physical v2.6）

1. 骨架和发片先完成蒙皮。在 N 面板打开 **`TEW Physical`**，可直接点击 **`一键自动识别物理骨骼链`**，或在姿态模式选中一条连续发束骨骼添加/更新链。
   - **实机推荐参数**：前刘海建议**直接锁死（不加链）**或选 **`近刚性贴额刘海`（700 / 0.56 / 1.8）** 防穿额遮眼；鬓角/侧发推荐 **`稳重低幅侧发`（520 / 0.50 / 3.0）**；长发/双马尾选 **`柔软长发`（95 / 0.22 / 14）**。
2. 点击 **`一键生成默认人形 5 碰撞体`**（`head`, `neck_00`, `spine_02`, `l_shoulder`, `r_shoulder`），在 3D 视口选中 `TEWCol_*` 球体用 `G/S` 调整包覆后点击 **`从视口同步回数据`**。
3. 可在时间轴点 **`烘焙物理预览`** 检查飘动和碰撞（导出前记得点 **`恢复原动作`**）。
4. 最后点击 **`一键同步导出 BMD6 + tew1_dyn.bin`** 生成游戏可直接加载的 `base/generated/tew1_dyn.bin` (v2)，并可另存 `.tew1-hair.json` 供其他章节模型复用。
5. 游戏内默认按 **`` ` ``（Tab 上方波浪键）** 打开/关闭物理/差分/透纱/自发光控制菜单（可在菜单 `[9]` 自定义改键，自动保存到 `tew1_dyn_hotkey.ini`）。
