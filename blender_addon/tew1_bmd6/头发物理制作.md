# TEW1 Blender 头发物理

1. 骨架和发片先完成蒙皮。在姿态模式选中一条连续的发束骨骼，在 N 面板打开「TEW1 → 头发物理」，填写刚度、阻尼、重力及发束半径，然后点「保存所选发束」。再次选同一条发束可更新设置。
2. 为头、颈、肩和上背逐个加入碰撞体。选绑定骨骼，填写该骨骼局部坐标中的两个端点及半径。两个端点相同时是球，分开时是胶囊。再次保存相同名称会更新碰撞体。视口中的辅助球标示胶囊端点和半径。
3. 让骨架播放已有的头颈动画，设置场景帧范围和帧率，点「烘焙头发预览」。插件会在独立的动作中写入发束位移及旋转，并保留原动作。
4. 点「导出头发物理配置」生成 `.tew1-hair.json`，其中包含发束骨骼、静止坐标、刚度、阻尼、重力，以及绑定在各骨骼上的碰撞体。

JSON 是本插件的物理制作数据。原版 Havok Cloth 的 `.clh` 使用另一种资源格式，当前游戏加载器没有接入此 JSON。
