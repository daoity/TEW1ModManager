# 《恶灵附身 1》角色 Mod 制作

## 骨架和挂载目录

1. 从 Blender 的「文件 → 导入 → 恶灵附身 BMD6」导入目标角色的 BMD6。插件保留模板中的原生骨骼、蒙皮、UV 和网格槽。
2. 在 3D 视图按 N，打开「TEW1」页签。设置一个独立于游戏安装的「挂载目录」。
3. 要和 ModToolkit 互通，在 TEW1 面板导出骨骼预设，将输出的 import/TEW1_Sebastian.json 和 bone/TEW1_Sebastian.json 分别放到 ModToolkit 的 assets/presets/import 和 assets/presets/bone。再用 ModToolkit 的现有骨骼映射功能。不要把其他游戏的变换参数直接套到 TEW1。
4. 新网格需与 BMD6 模板在同一绑定空间，且有效顶点组使用目标骨骼名。选中新网格和模板骨架，在 F3 中用「替换 TEW1 网格槽」绑定到指定槽。BMD6 使用 +X 朝前、+Y 朝角色左侧、+Z 朝上。

## 材质怎么做

TEW1 导出器按游戏材质路径绑定，一个 BMD6 网格槽对应一个游戏材质。一个 Blender 网格有多个材质时，先按材质拆成多个可用网格槽。在 TEW1 面板选材质预设、底色 DDS 和游戏材质路径，然后点「生成 .decl 和 .bimage」。

| 材质预设 | 底色文件 |
| --- | --- |
| 衣服和皮肤 | BC1/DXT1 DDS，主体不透明 |
| 不透明发片 | BC1/DXT1 DDS，使用已经测试的发片参数 |
| 睫毛和透明裁切 | 保留 Alpha 通道的 BC3/DXT5 DDS |

DDS 可由 ModToolkit 或其他已有贴图工具生成。带 mip 的 DDS 会将相应 mip 写入游戏贴图。上述三种预设使用游戏自身的前向着色器和平坦法线，适用于此项目已验证的连续切线路线。替换原生虚拟纹理页的材质需要另外做 C/N/S 页布局。

例如在面板中填游戏材质路径 textures/creator/outfit，插件会写出：

~~~text
Mod根目录/
  base/generated/decls/material/textures/creator/outfit.decl
  base/generated/textures/textures/creator/outfit_c.bimage
  base/generated/nextgen/characters/pl/pl0020/model/pl0020_ng.bmd6model
~~~

- 模型引用为 textures/creator/outfit。
- outfit.decl 的 transmap 指向 textures/creator/outfit_c。
- 贴图目录中的两层 textures 都要保留。外层是生成资源目录，内层是游戏纹理引用的一部分。
- Blender 材质节点可作为预览。游戏实际读 .decl 及其引用的 .bimage。
- 程序从模板保留模型资源路径。点「导出模型到挂载目录」后，把整个 base 文件夹压缩成 ZIP，再拖入管理器验证。ZIP 文件名和显示名支持中文。上例这样的游戏内资源名使用小写英文、数字、下划线和斜杠。
