# TEW1 全章节模型、断肢 `meshKits` 与原生 CG 嘴型规范

## 1. 全章节主角模型清单与断肢道具

- **主游玩/过场全套模型**：
  - `pl0000_ng`（常规全章节核心模型，共 31 表面上限最紧张！）
  - `pl0010_ng`, `pl0011_ng`, `pl0012_ng`, `pl0210_ng`（CG/特写多嘴骨头模）
  - `pl0017_ng`, `pl0018_ng`, `pl0020_ng`（特殊章节服装/病院/终章变体）
  - `pl0201_ng`, `pl0220_*`, `pl0230_ng`, `em5002_ng`（变体/特殊剧情模型）
- **断肢独立掉落道具模型**：
  - `pl0001_ng` / `pl0016_ng`：被斩下的独立头颅（必须包含自定义头发、头饰及从身体拆分出来的耳朵/上颈皮肤 `head_skin`，槽位放 `m_face1` / `m_face`）
  - `pl0002`：断右臂 | `pl0003`：断左臂 | `pl0004`：断右腿 | `pl0005`：断左腿 | `pl0008`：断右手
- **必须 100% 隐藏的特殊模型**：
  - `pl0007`：全章节包中必须将其全部表面清零隐藏（`0` 活三角面），否则某些剧情/检查点下角色脚底会出现一团折叠的废网格。

## 2. 体型对骨黄金法则（防双开门 / 1:1 脚掌 / 平滑腰胯 / 防内衣穿模）

1. **还原原版窄肩（彻底消除“双开门”方形肩垫）**：
   - **几何对骨**：对 `l_shoulder`/`r_shoulder` 与 `l_upperarm`/`r_upperarm` 保持 **`0%` Y 轴外扩**（仅保留轻度 Z 轴高度过渡 `0.10/0.20`，再经肘部 `0.50 X / 0.35 Y / 0.50 Z` 平滑桥接到塞巴斯蒂安手腕 `target_wrist`）。
   - **内侧肩头权重转移（最核心！）**：塞巴斯蒂安原生上臂旋转轴心在 `|Y| ≈ 10.25`，女性/二次元角色实际肩头在 `|Y| ≈ 5.8~6.8`。如果不改权重，角色在待机垂臂 ~42° 时，位于轴心内侧（`|Y| < 10.6`）且绑在 `upperarm` 上的肩头皮肤会被绕外侧轴心**向上抬起（+Z）**形成方形“双开门”。
   - **标准公式**：对所有 `|Y| < |tgt_upperarm.y| + 0.35` 的顶点，计算 `t = clamp((|Y| - src_upperarm_y) / (cutoff - src_upperarm_y), 0, 1)`，`keep = t*t*(3 - 2*t)`，将 `w_upperarm * (1 - keep)` 从 `l_upperarm`/`r_upperarm` 转移至 `l_shoulder`/`r_shoulder`。Blender 插件 v2.6 已将其内置进「一键对骨」与独立按钮 **`一键修复「双开门」肩宽权重`**。
2. **还原原版 1:1 脚掌比例（绝不拉长成高帮战靴大脚）**：
   - 塞巴斯蒂安穿着厚底高帮军靴，`l_foot`/`r_foot` 骨头很高且脚掌很长。如果直接按 `foot_length` / `shoe_height` 缩放，或把裸足脚踝强行对齐到 `tgt_foot.z`，裸足会被拉长 `1.45×`、拉高 `1.60×` 或悬空。
   - **标准做法**：
     - 全局身高缩放用 **`head.z - 真实脚底最低顶点Z`** 对比 `tgt_head.z - 0.10`；
     - 全局 Z 对齐直接把**真实脚底最低顶点贴地至 `Z = 0.10`**；
     - 脚部骨骼 `l_foot`/`r_foot`/`l_toe`/`r_toe` 保持 **`np.eye(3)` 刚体 1:1 平移**（`new_ankle.z = ankle.z`），绝不缩放脚长与脚高。
3. **C1 平滑腰胯过渡（消除腰部/大腿根折痕）**：
   - 全局前后 X 必须按**双大腿根中点 X**（`0.5*(tgt_l_thigh.x + tgt_r_thigh.x) - 0.5*(src_l_thigh.x + src_r_thigh.x)`）对齐，避免 `pelvis` 与 `thigh` 之间产生前后错位。
   - `spine_02 -> spine_01 -> pelvis -> thigh` 采用共享关节 C1 连续链（`hip_z_fit ≈ 0.46`），骨盆与臀部区域保留柔滑 `pelvis`/`thigh` 混合权重（如有 `Butt_L/R` 等辅助骨，平滑分配权重）。
4. **头身皮肤彻底分离（防身体顶部长出耳朵/头皮）**：
   - 部分二次元源模型的身体贴图材质（如 `000_Face(BodySkin)`）在脖颈以上仍连着耳朵、耳后或上颈面片。拆分断肢与导出前，必须按材质或脖颈高度将所有头/耳部皮肤划归 `HEAD` 槽（`m_face`）并同步写入断头道具 `pl0001_ng`/`pl0016_ng`，保证身体网格严格终止在脖颈下方。
5. **贴身内裤/内衣防穿模**：
   - 与皮肤共面的紧身内衣（特别是后腰/臀部弯曲处）在动画中极易穿出皮肤。必须使用 KDTree 检测距皮肤 `< 0.35` 的内衣顶点，沿皮肤法线微幅外推（后侧 `-X` 推 `0.22`，前/侧推 `0.12`），并**精确复制最近皮肤顶点的骨骼权重**（确保与臀腿 100% 同步运动）。Blender 插件 v2.6 提供一键按钮 **`贴身内衣/内裤防穿模`**。
6. **顶点色身体补丁烘焙规范**：
   - 源模型若使用顶点色无 UV 补丁面片，严禁使用 Blender `smart_project` 自动展 UV（易导致密集小岛在 1px 边缘渗黑）；应使用前后正交平面投影 UV，按相邻皮肤顶点做接缝色匹配，并对贴图执行 16px 边缘扩张（Dilation）。

## 3. 断肢 `meshKits` 核心机制（`pl0000.md6.decl`）

1. **引擎表面匹配逻辑（RVA `0x17A260`）**：
   - 引擎按 `meshKit` 名称表遍历全部表面，**所有名称匹配的表面都会被同时隐藏或显示**（因此允许存在多个同名 `m_face` 表面，非常适合放自定义脸、头发、发饰！）。
2. **严禁踩雷的“断头残留”陷阱槽**：
   - `m_beard`, `m_beard1`, `m_Cornea`：在 `headdamage`（爆头/部分断头）状态仍保持可见！
   - `m_vest__nv`, `m_holster__lt`, `m_coat_button`, `m_hand_r`, `m_necktie`：属于身体槽，在 `headless` / `headdamage` 处决时完全不隐藏！
   - **正确做法**：自定义头发、眉毛、睫毛、面部、发饰**一律**放到真头部槽：
     - `pl0000_ng` / `pl0017_ng` / `pl0018_ng` / `pl0220_*` / `pl0230_ng` / `em5002_ng` → `m_face`
     - `pl0020_ng` → `m_mouth3`
     - `pl0201_ng` → `m_tong`
3. **四肢断肢拆分规则（以 `pl0000_ng` 为例）**：
   - 若将整件衣服/身体全塞在 `m_shirt__nn`，断臂/断腿处决时肢体不会消失。
   - 正确拆分（Blender 插件 `TEW Mesh` 提供一键自动按骨骼权重拆分按钮）：
     - 躯干 → `m_shirt__nn`
     - 左臂（`l_shoulder/l_upperarm/l_forearm/l_hand/l_手指*`） → `m_hand_l`
     - 右臂（`r_shoulder/r_upperarm/r_forearm/r_hand/r_手指*`） → `m_r_shrit_arm__na`
     - 双腿/靴子（`l/r_thigh`, `l/r_shin`, `l/r_foot`, `l/r_toe`） → `m_pants_leg__np`
4. **总表面数 `<= 31` 与 Havok `m_hair` 规则**：
   - 原版 `m_hair` 保留原始顶点数，仅将三角面索引设为零面积退化三角形 `(0, 0, 0)`，防止 Havok `.clh` 布料初始化崩溃。
   - 若新增了自定义表面导致总数 `> 31`，必须合并同材质/同断肢槽部件或复用安全空槽，确保总表面 `<= 31`。

## 4. 原生 9 骨 CG 嘴型与受击/死亡表情协调

- **为什么嘴部必须走原生骨骼？**
  - 游戏 CG 过场和对话由原生骨架驱动 `jaw` 与嘴周骨骼；如果运行时 DLL 长期覆写嘴部顶点或未给嘴唇/下牙刷 `jaw` 权重，CG 里主角说话嘴巴不会动。
- **原生 9 根嘴骨映射（`patch_haruka_mouth_jaw.py`）**：
  - 高精度头模（`pl0010_ng`, `pl0011_ng`, `pl0012_ng`, `pl0210_ng`）：`jaw`, `mouth_u_middle`, `mouth_u_l`, `mouth_u_r`, `mouth_d_middle`, `mouth_d_l`, `mouth_d_r`, `mouth_u_l_corner`, `mouth_u_r_corner`, `mouth_d_l_corner`, `mouth_d_r_corner`。
  - 全部 16 个头模：下唇、下牙齿、舌头顶点（`LOWER_MOUTH`）赋予平滑 `jaw` 权重，确保张嘴时不穿模。
- **运行时形态键幅度纪律**：
  - 待机与 CG 过场：`M_A` 等嘴型形态键保持 `0.0`，完全交由原生骨架驱动。
  - 眨眼：仅驱动 `M_BLINK`。
  - 受击：驱动皱眉/愁眉/眯眼，并叠加轻度 `M_A = 0.28`（严禁开到 `0.6+`，否则下牙齿容易穿出下巴）。
  - 死亡：闭眼 + 愁眉 + 极微张嘴 `M_A = 0.12`。

## 5. 读取 `.tangoresource` 重复记录避坑
- 在 `claws_of_the_horde.tangoresource` 等档案中，`pl0000.md6.decl` 存在多条同名条目；读取时若 `len(entries) > 1`，应取体积最大的记录并用 `zlib.decompressobj(-15)` 原始 deflate 解压。
